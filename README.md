# ReviewShield AI

Purpose
- Lightweight local/development frontend + backend for review analysis and demo purposes.

Quick start
1. Copy environment vars from `.env.example` to `.env.local` and fill values.
2. Install dependencies:

```bash
npm install
```

3. Run in development:

```bash
npm run dev
```

Notes
- Do NOT commit secrets. Use `.env.local` and keep `.env` files excluded by `.gitignore`.
- Sensitive/demo data (e.g., `data/db.json`) has been removed from the repository.

Files changed
- Removed local demo DB and other unneeded files prior to publish.

See `.gitignore` for ignored files and `.env.example` for required environment variables.
